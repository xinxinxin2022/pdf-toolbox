# PDFToolBox 📄

Free online PDF tools — 100% private, no upload required.

## Features

- 📎 **Merge PDF** — Combine multiple PDF files into one
- ✂️ **Split PDF** — Extract pages from PDF
- 🗜️ **Compress PDF** — Reduce file size
- 📝 **PDF to Word** — Convert PDF to Word document
- 🖼️ **PDF to JPG** — Convert PDF pages to images
- 📄 **JPG to PDF** — Convert images to PDF
- 📊 **PDF to Excel** — Extract tables from PDF
- 📝 **Word to PDF** — Convert Word to PDF
- 🔄 **Rotate PDF** — Rotate PDF pages
- 🔢 **Add Page Numbers** — Add page numbers to PDF
- 💧 **Watermark PDF** — Add watermark to PDF
- 🔓 **Unlock PDF** — Remove PDF password

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- pdf-lib.js
- PDF.js
- react-i18next

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Push to `main` branch — GitHub Actions will auto-deploy to GitHub Pages.

## Privacy

All PDF processing happens in your browser. No files are uploaded to any server.
